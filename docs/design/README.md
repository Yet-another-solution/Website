# Design files

`design.pen` is the Pencil design the October 2026 redesign was built from. Open
it with the Pencil app (pencil.dev).

It holds an import of every page as it was before the redesign, the redesigned
screens with their shared components, and the improved homepage. The images
beside it (`embedded-image*.png`, `images/`, `untitled-assets/`) are referenced
by the file with relative paths, so keep them next to it.

Nothing in this folder is part of the built site: Astro only ships `src/` and
`public/`.

The site has since moved on from these screens in places (per-page backdrops,
full-screen homepage bands, project galleries), so treat the file as the
starting point, not as the current state.
