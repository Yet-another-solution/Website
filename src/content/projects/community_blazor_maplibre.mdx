## What is Community.Blazor.MapLibre?

Community.Blazor.MapLibre is an open-source C# wrapper around [MapLibre GL JS](https://maplibre.org/), the open-source library for interactive vector maps. It puts interactive maps into Blazor applications and lets you control them from C# through a clean, idiomatic API, so you do not have to write the JavaScript interop yourself. Y-A-S builds and maintains it.

## How do I install it?

Add the package from NuGet:

```bash
dotnet add package Community.Blazor.MapLibre
```

Then place the component in a Razor page:

```razor
<MapLibre />
```

To customise the map, pass it a `MapOptions` object:

```razor
<MapLibre Options="_mapOptions"></MapLibre>
```

The [documentation](https://yet-another-solution.github.io/Blazor.MapLibre/) covers the rest of the setup, including the stylesheet to load in your page's `<head>`.

## What can it do?

The documentation has a working example for each feature: adding markers and popups, listening to map events, fitting the map to bounds, loading GeoJSON, drawing shapes with Mapbox GL Draw, showing several maps on one page and rendering the map as a 3D globe.

## Adoption

As of November 2026, the package has over 23,000 downloads on [NuGet](https://www.nuget.org/packages/Community.Blazor.MapLibre), and the [GitHub repository](https://github.com/Yet-another-solution/Blazor.MapLibre) has 33 stars.

## Who maintains it?

Y-A-S ApS, a software studio in Esbjerg, Denmark. Custom web applications in C# and Blazor are what we build, so if you need interactive maps in one, we can help.
